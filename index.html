个人AI Agent使用记录

自我介绍

我是人工智能专业大三学生，本页面记录我日常学习、写代码、做实验使用的AI Agent工具，包括用途和实际效果。

Agent 1：代码辅助Agent（Cursor）

用来做的事情：Python、OpenCV、机器学习代码编写、bug排查、实验代码注释改写，帮我理解算法逻辑，生成可调试代码。

取得的效果：减少重复基础代码编写时间，快速定位报错；在图像插值、神经网络实验作业中，缩短调试周期；同时我会自己阅读、修改代码，加深算法理解。

Agent 2：长文档阅读Agent（Kimi智能体）

用来做的事情：阅读论文、课程PDF、课件，提取核心原理、整理实验思路，对比多篇文献观点。

取得的效果：快速看懂外文论文，节省文献阅读时间；帮我梳理实验报告结构，提炼原理；适合课前预习和课程作业资料整理。

Agent 3：通用多任务Agent（豆包Agent）

用来做的事情：实验报告文字润色、知识点答疑、算法原理通俗讲解、构思项目方案、整理复习提纲。

取得的效果：遇到难懂概念可以快速获得解释；辅助撰写规范的实验报告；帮助梳理知识框架，用来备考和完成课程大作业。

总结

AI Agent对我来说是学习辅助工具，我不会直接复制结果上交，会核验、修改、复现，用来提升学习效率，聚焦算法原理理解。
